- Identifier: `OneColArticleCard`. The Figma name "1Col Article Card" starts with a digit, which a JavaScript function name can't; CSS classes keep the repo slug (`mngds-1col-article-card`).
- `style` is the Figma Style variant (a string). Because React also uses `style` for inline styles, an object passed as `style` goes to the root as inline styles and Style stays Standard.
- Headline uses the editorial styles the spec names in its summary (and the documentation frame): `Editorial/Titles/CardQuaternary` for Standard and `Editorial/Titles/TitleMedia` for Media Lead, instead of the literal "Noto Sans" / "Noto Serif" headline tokens. Sizes, weights, line heights and letter spacing are the same (19/24, −0.035em = −0.665px; 29/33, −0.04em = −1.16px); the family now follows the theme (Measured Vibrant renders the Standard headline in Noto Serif, Modern Earthy the Media Lead headline in Noto Sans).
- Excerpt uses `Editorial/Body/ExcerptCompact` (Standard, 15/19) and `Editorial/Body/Excerpt` (Media Lead, 15/21), as the summary names them. Contradiction: the Standard excerpt font-family token is `{font.theme.small-headline-family}`, but ExcerptCompact uses `font.theme.body-family`; Media Lead's token is the literal "Noto Sans". Followed the named style (body family), so Modern Earthy shows the excerpt in Noto Serif.
- Subscriber badge: the Article Status Badge (Type=Subscriber) has no current export and isn't its own component here. Built inline from the legacy export (`figma-exports/mng-design-system-export/homepage/components/01-article-status-badge/`): `color/theme/primary` fill, 2px / 5px padding, Noto Sans SemiBold 13, line height 22.65px, uppercase, `color/gray/max` text (127×27 in Figma; renders 126.7×26.66).
- Meta: plain text, Noto Sans Regular 13, line height normal, `color/gray/200` (skeleton), without the Article Timestamp clock icon, as in the skeleton. It becomes `<time>` when `dateTime` is given.
- Image: `aspect-ratio` 4:3 (Standard) and 16:9 (Media Lead) from the spec summary, so the card fills its column; at 296px this gives the 222 / 166.5px height tokens. The 296px root and graphic width tokens are used only as the preview width.
- Link: Figma draws no hover or focus state. With `href` the headline text is the link (`color: inherit`, no underline); the browser's default focus ring is kept.
- Bottom rule: a 0-height div with a 1px top border. It takes 1px of layout where the Figma line takes 0 (Standard 373 vs 372; Media Lead 414.4 vs 413.5, also because TitleMedia's 1.1379 line height gives 32.998px lines).
- The placeholder label in the Figma PNGs has a light halo behind "GRAPHIC / IMAGE"; that comes from the runtime `ArticleImage`, not this component.
- Contrast (same in all three themes): headline `color/gray/min` 18.42:1, excerpt `color/gray/100` 11.56:1, meta `color/gray/200` 6.57:1 on `color/gray/max`; badge `color/gray/max` on `color/theme/primary` 5.45 / 6.87 / 5.20:1 (Bold Coastal / Measured Vibrant / Modern Earthy). All pass.
