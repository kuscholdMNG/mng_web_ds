- Non-modal dialog: `role="dialog"`, `aria-modal="false"`, labelled by the title. The panel has no overlay and the page stays interactive, so `aria-modal="true"` would wrongly hide the page from assistive tech; there is no focus trap.
- Float placement is an open spec item (known issue 1): Float renders in flow and the consumer positions it. FixedFooter is `position: fixed` at the bottom, 16px (`spacing/200`) from each side, unless `inline`.
- Layout is one structure for every variant (the Figma layers differ: Panel › Contents Frame › Title/Main on XLDesktop OneTapCTA, Contents › Frame 11508 elsewhere); spacing follows each variant's skeleton: 16px between title, Apple button and chooser; XLDesktop OneTapCTA adds Main's 8px above and below the button; FixedFooter keeps 32px right of the title; XLDesktop GOTcustom/AllOptions center the mark on the title, the others top-align it with 4px padding. All nine variants match the Figma sizes exactly (546×192/321/422, 328×187/359/433, 308×214/359/460).
- Button Pay (Sign in with Apple) has no export in this repo. Size from the component tokens (249×58 incl. Button Pay's 8px side padding and 8px gap, from the skeleton); its look is read from the documentation and variant PNGs: `color/gray/min` fill, 1px `color/gray/400` edge, label Noto Sans SemiBold 19 `color/gray/max` (documentation text "Apple's style (SemiBold 19, white)"), `appleinc` icon at 24px. Corner radius isn't recorded anywhere; the PNG shows about 2px, drawn with `radius/sm` (4px). Needs a Button Pay export.
- UserImage avatars use the legacy export (`figma-exports/mng-design-system-export/menus-and-parts/components/34-userimage`, no current export): unknown = `color/gray/max` circle + 16px `user` icon; monogram = #FF702C (unbound in Figma) with Noto Sans Regular 12 `color/gray/min`; photo = `image`. The Figma "Phillip Phanatic" photo isn't in the repo, so the preview shows the image slot's `color/gray/500` fallback.
- `google-color` is a four-layer icon (tokens/icons/icons.json `layers`); `Icon` draws only the first layer, so the panel stacks the four glyphs itself with the layer colors from icons.json (first = the token's #4285f4). Shared change suggested: layered-icon support in `Icon`.
- Divider lines are 0px tall in Figma (Line, height 0, 1px stroke); drawn with a −1px margin so they add no height (the skeleton's `border: 1px` on a 0px box would add 2px each).
- Account text columns are fixed 194/235px in Figma; here they fill the row (same result at the Figma widths, and no overflow on narrower panels).
- Long titles wrap after a dot in the domain ("fakevilledailynews." / "com"), as in the XSFold previews.
- Account rows and "1 more account" are `<button>`s with a 2px `color/gray/black` focus outline drawn inside the row (no focus state in Figma).
- Duplicate token groups (`base.contents.frame-11508…`, `base.contents.frame-12702…`, `base.panel…`, `options-*…`) carry identical values; one of each is used.
