- Headline letter-spacing: the tokens say `-3px` (base and mobile), but the spec prose says −0.87px at 640px and up and −0.03em below (−0.87px is −3% of 29). Used `-0.03em` at every size, following the spec: the token looks like a percent read as px.
- Headline family, size, weight, line height and color come from the component tokens (`font/family/noto-serif`, 29/33, Mobile 25/29). The spec names no editorial style, so the headline stays Noto Serif in every theme. The excerpt's literal "Noto Sans" uses `--mng-font-family-noto-sans`; its size, weight, line height and color are the component tokens.
- Related Article List Item has no current export. Built from the legacy export (`figma-exports/mng-design-system-export/homepage/components/02-related-article-list-item/`): 22px bullet column (8px padding, 6px round `color/gray/min` dot with a 1px `color/gray/600` inside stroke), title Noto Serif Bold 12/15 `color/gray/min`, time Noto Sans Regular 11, line height 20.63px, `color/gray/200`. The 12/15 and 20.63px line heights are raw (no tokens).
- Related item height: Figma fixes the items at 45 / 41 / 41px (`related-article-list-item.height` token 41px), but a two-line title plus the time is 50.63px, so in Figma the time runs over the next item's box. Here 41px is a `min-height`: items grow with their content, so longer titles never overlap. This makes the Related list 24.9px taller than Figma with the sample titles. The "Related" header adds 2px more (18 vs 16: the browser's normal line height for Noto Serif 12 is 17px, and the 1px underline is a border here where Figma draws a stroke outside the layout). Totals: Desktop and Tablet 375.9 vs 349; Mobile 652.5 vs 632.66. Switch to a fixed `height` only if the overlap is intended.
- Mobile top gap: Figma's Mobile variants start with an empty "SubsOnly Frame" (it holds the hidden Article Status Badge, Type=None), which adds 8px above the headline. The card has no badge property, so the empty frame isn't rendered (8px shorter on Mobile, before the item-height difference above).
- Mobile image: full width at the 340 × 235.65 shape (`aspect-ratio: 340 / 235.65`, from the featured-image tokens), so it scales with the card instead of keeping a fixed 235.65px height.
- Gallery=Slideshow renders `Zone1Slideshow` with `breakpoint` = `device` (Desktop 356, Tablet 358 wide; 359 / 319px tall, matching the 2nd-col tokens). On Mobile it also gets `fill` so it spans the card (309.25px tall at 340 vs the 309 token: the fill mode's 16:9 area is 191.25 vs 191). `slideshow` props override both.
- Desktop: Image hugs (295 + 20 + 391 = 706); Slideshow uses the 706px root-width token with space-between, as the skeleton does. Tablet hugs (358 + 32 + 358) and the 391px image overflows its column (spec known issue 1). Mobile fills its container (`width: 100%`; 340 is the preview width).
- One-column layout from 800 to 1279px (spec: the third page column narrows the lead): the documentation frame says production keeps the 29/33 headline there, but the only one-column variant (Mobile) is 25/29. Use `device: 'Mobile'` for the layout; the headline size there is a spec gap.
- Link: Figma draws no hover or focus state. With `href` the headline is the link, and each related item with an `href` links its title (`color: inherit`, no underline); the browser's default focus ring is kept. The Related list is a `<ul>` with `aria-labelledby` pointing at the "Related" header; bullets are `aria-hidden`.
- Mobile bottom rule: a 0-height div with a 1px top border; it takes 1px of layout where the Figma line takes 0.
- Contrast (same in all three themes, on `color/gray/max`): headline and related titles `color/gray/min` 18.42:1, excerpt `color/gray/100` 11.56:1, "Related" header and related times `color/gray/200` 6.57:1. All pass.
