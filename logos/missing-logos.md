# Missing newspaper logos

> **Updated 2026-10-30.** What's still missing from the Figma `Logo` component (Newspaper Logos, Favicons, User Pics, `oXaN4tEoa4GsH4x7kWpAFZ`, set `389:385`), and what to ask Marketing for. Every slot listed here shows the magenta placeholder box in Figma. When a file arrives, update this list, swap the variant in Figma and update the status doc (open item 10).

## The rules (Karl, 2026-10-30)

- **Official artwork only.** Every logo comes from Marketing's Drive folder "Completed Market Logos" (owner Kristen Althoff), imported as is: the artboard's "Art" layer, paste-board background removed, cropped to the logo, scaled to 64 px (Horizontal) or 128 px (Stacked, Lettermark). Never redrawn, recolored, or taken from art already in Figma. Nothing is invented.
- **Horizontal** comes from the `<ABBR>_PageSuite.ai` file (artboard 2). Its other ink and its Color version come from `<ABBR>_LogosMaster.ai` (artboards 3 / 6 / 9) only when the LogosMaster Main Logo matches the PageSuite logo.
- **Stacked** and **Lettermark** come from `<ABBR>_LogosMaster.ai`: black 4 / 5, white 7 / 8, color 10 / 11 (The Baltimore Sun: 5 / 6 and 8 / 9).
- **Light** = the black-ink artboard, **Dark** = the white-ink artboard, **Color** = the brand-color artboard.
- **No official file = magenta box:** an empty rectangle with an 8 px inside stroke in `#ff00ff`, the size of that market's logo in the same layout (or the column's typical size). Its variant description starts with "PLACEHOLDER".
- Unusual official art (embedded photos, image traces, alternate lockups) goes to Karl to decide before it is used.

## Summary

- **343 of 873 market slots** (97 markets × 3 layouts × 3 colors) have no official file yet.
- **14 publications have no artwork at all:** Sonoma County Gazette, Silicon Valley, Colorado Daily, Lamar Ledger, BoCoPreps, Brush News-Tribune, Buffzone, South Platte Sentinel, The Burlington Record, Excelsior California, Daily Herald, The Willits News, GrowthSpotter, Sonoma Magazine.
- **4 publications have only one horizontal logo** and no LogosMaster file: Julesburg Advocate, Akron News-Reporter, San Gabriel Valley Tribune, Monterey Herald.
- **65 publications are missing some or all color versions** (everything else is in place).

## What to ask Marketing for

1. A full LogosMaster file (black, white and color: horizontal, stacked, lettermark) for each publication with no artwork at all.
2. A LogosMaster file for the publications that only have one horizontal logo.
3. Color artboards (9 horizontal, 10 stacked, 11 lettermark) for the LogosMaster files that stop at artboard 8, and artwork on the color artboards that are empty.
4. Clean vector color versions for Longmont Times-Call, Woodland Daily Democrat and St. Paul Pioneer Press (see the table).
